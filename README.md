* **Опис роботи:**
  Інтерфейс розробленої програми складається з вікна форми, на якому розміщено елементи керування для взаємодії з користувачем та вільну область для малювання.

**Основні елементи інтерфейсу:**

* **ListBox (Список фігур):** Розташований у правій частині форми. Він містить текстовий перелік із 9 графічних об'єктів, доступних для побудови (лінія, прямокутник, зафарбований прямокутник, еліпс, зафарбований еліпс, сектор, зірка, трикутник, будиночок).


* **ComboBox (Випадаючий список):** Розміщений безпосередньо під списком фігур. Він призначений для вибору кольору пензля та олівця, якими малюватиметься фігура.


* **Робоча область (Полотно):** Порожня ліва та центральна частина форми, де безпосередньо відображається результат відмальовування графічних примітивів.



**Принцип роботи програми:**
Програма працює як найпростіший інтерактивний графічний редактор на основі обробки подій. Користувач розгортає випадаючий список (`ComboBox`) і обирає бажаний колір. Після цього він клікає на назву потрібної фігури у переліку `ListBox`. Програма миттєво обробляє цю подію (`SelectedIndexChanged`), очищає попередній малюнок на робочій області та відмальовує обрану геометричну фігуру (або багатокутник) із застосуванням заданого користувачем кольору.

* **Опис роботи:**
  Інтерфейс розробленої програми для другого завдання складається з простого вікна форми з малюнком та кнопками керування.

**Основні елементи інтерфейсу:**

* **Область зображення (PictureBox):** Розташована у лівій частині форми. Вона використовується для виведення кадрів анімації — на скриншоті показано відображення світлофора з увімкненим жовтим сигналом.


* **Кнопки керування (Buttons):** Справа від зображення знаходяться дві кнопки. Верхня кнопка **«Start»** призначена для запуску процесу, а нижня **«Stop»** — для його примусової зупинки.



**Принцип роботи програми:**
Програма реалізує найпростішу покадрову анімацію, використовуючи компоненти `Timer` для відліку часу. Після натискання на кнопку «Start» програма запускає прихований таймер, який через рівні проміжки часу автоматично змінює видимість підготовлених картинок (перемикає кольори світлофора). Це створює ілюзію неперервного руху чи зміни стану. Клік по кнопці «Stop» призупиняє роботу таймерів і заморожує зміну кадрів.

* **Опис роботи:** 
Інтерфейс програми для третього завдання являє собою простий інтерактивний аудіословник.

**Основні елементи інтерфейсу:**

* **Ілюстрація (PictureBox):** У верхній частині форми розміщено велике графічне зображення. На ньому у вигляді зручної таблиці представлені різні варіанти привітань англійською мовою з українським перекладом та візуальними асоціаціями (рукостискання, годинник, сонце, місяць тощо).
* **Список слів (ListBox):** Розташований у лівому нижньому куті форми. Він містить перелік доступних для прослуховування фраз українською мовою. На наданому скриншоті у списку синім кольором виділено пункт «Вечір».
* **Кнопка відтворення (Button):** Справа від списку знаходиться велика прямокутна кнопка з написом «Play».

**Принцип роботи програми:**
Користувач використовує програму для вивчення вимови слів. Спочатку він вибирає потрібну фразу зі списку зліва, орієнтуючись на картинку-підказку зверху. Вибравши слово (наприклад, «Вечір»), користувач натискає кнопку «Play». У цей момент програма зчитує, який саме рядок виділено у списку, і запускає відтворення відповідного цьому слову звукового файлу.


## 📝 Висновки

**Висновок:**

Під час виконання лабораторної роботи я ознайомилася з інструментами для роботи з графікою, анімацією та звуком у середовищі MS Visual Studio (C++ Windows Forms).

Зокрема, я здобула та закріпила такі практичні навички:

* **Побудова графічних примітивів:** навчилася використовувати класи `Graphics`, `Pen` та `Brush`, а також їхні базові методи (DrawLine, FillRectangle, DrawEllipse, DrawPolygon тощо) для малювання і зафарбовування геометричних фігур на формі.
* **Створення анімації:** засвоїла принципи створення простої покадрової анімації за допомогою компонента `Timer` та динамічного керування властивостями елементів (перемикання видимості зображень у `PictureBox`).
* **Робота зі звуком:** навчилася інтегрувати в розроблену програму аудіофайли формату `.wav` за допомогою об'єктів класу `System::Media::SoundPlayer` та налаштовувати їх відтворення за певними умовами.
* **Проєктування інтерфейсу:** вдосконалила вміння працювати з візуальними компонентами (`ListBox`, `ComboBox`, `Button`, `PictureBox`), пов'язувати їхню логіку між собою (наприклад, вибір кольору чи фігури зі списку) та писати обробники подій для створення повноцінних інтерактивних додатків.

Загалом, мета лабораторної роботи досягнута: я успішно розробила програмні модулі, що поєднують графічне відображення, анімаційні ефекти та звуковий супровід.
